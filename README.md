## ✨ Features

### 🎮 Game Features
- 💰 **Money Boost** - Add money to your account instantly
- ⭐ **XP Boost** - Level up faster
- 🚗 **Vehicle Unlock** - Unlock any car in the game
- 🔓 **Unlock All Cars** - Get every car in the game
- 🏎️ **Car Speed Hack** - Modify car performance
- 🎨 **Custom Liveries** - Copy liveries between cars
- 🏠 **Unlock Houses** - Unlock all in-game houses
- 👑 **Unlock Crown** - Get the crown
- 🔧 **Engine Mods** - Disable engine damage, unlimited fuel
- 👕 **Customization** - Unlock all clothes and accessories

- 🌈 **Animated RGB Colors** - Beautiful terminal interface
- 📊 **Progress Bar** - Visual loading animations
- 🎬 **Typewriter Effect** - Smooth text display
- ✨ **Pulse Effects** - Dynamic visual feedback
- 📱 **Mobile Optimized** - Works perfectly in Termux

- 💰 **Points System** - Pay-as-you-use model

## 🚀 Installation

### Method 1: Quick Install (Recommended)

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/CPM-Eclipse.git

# Navigate to folder
cd CPM-Eclipse

# Run install script
chmod +x install.sh
./install.sh

# Configure
cp config.example.json config.json
nano config.json

# Run the tool
./eclipse.sh
